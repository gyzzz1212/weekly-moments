# 自律空间 · 0.7.1 提醒响应修复版

面向 Mate 60 Pro / HarmonyOS 4.x 的独立 Android 应用。保留微信聊天，限制进入个人朋友圈；支持每7天一次、累计15分钟、最多手动暂停3次。新增周计划、每日重点、课外短时计划、作息记录与离线AI知识卡。界面使用深蓝、冰蓝、淡紫的简约科技配色。不是微信修改版。

**构建和规则检查通过不等于华为实机验证通过。** 当前没有连接用户手机；页面识别、微信语音来电、后台提醒与动画仍需实机验证。iPad Air 无法安装本APK；本项目未实现iPad版全手机拦截。

本轮界面与音效说明见 dist/0.5界面试用说明.md。原有功能说明见 dist/安装与使用.md、dist/0.4功能指南.md。

## 功能

- 朋友圈累计15分钟，手动暂停不扣时间；离开微信不会自动暂停。每次暂停计一次，最多3次，第三次恢复后计时到用完。剩余额度在本次开始后7天到期；提前结束不退回。
- 周计划周日00:00换周，首次使用普通应用时要求填写。待办、完成勾选、习惯和娱乐目标均手动记录。可设允许星期、每日分钟上限、每周次数目标，空白实际记录不算成功。
- 周六目标就寝时依次跟进到期短时计划、日复盘、周复盘；跨午夜就寝仍归属周六。之前未做的周复盘保留。
- 日计划同步展示周计划，短时计划同步展示日计划。30/60/90/120分钟计划避开已确认课程及睡眠，结束后逐项记录完成比例，按预计分钟加权。
- 起床、就寝目标和循环时段随时可改；支持补记、修正，统计是自报确认时间，不是睡眠传感器数据。改进建议由本机统计规则产生，不调用远程大模型。
- 每天3张AI卡片，14天42张入门后顺序复习。原创中文短文、练习与示意图；内置课程与论文延伸链接。漏读次日先补最早欠读，暂停投放期间不产生新卡，重新启用保留之前欠读。
- 电话、系统时钟、通话状态、设置和紧急退出优先避让。全手机跟进只在用户启用、服务运行、手机解锁时显示。没有禁用卸载或读取娱乐应用使用记录。

## 隐私边界

Manifest 声明联网、通知、准时提醒、开机完成四项权限。联网仅用于邮箱账号和主动云备份；无障碍服务不发起联网请求。没有录音、摄像头、联系人、通话记录、短信、使用记录或读取整个相册权限；关闭 Android 应用自动备份。

无障碍服务仅订阅窗口切换事件，接收应用标识、页面类名与窗口编号。`canRetrieveWindowContent=false`，未请求截图或按键过滤能力，没有节点树、事件文本或输入内容读取代码。最近微信类名只保留在内存；升级时清除旧版曾保存的最近类名。没有读取或记录支付密码的功能。

手动填写的目标、课表、作息、完成情况、阅读打勾与紧急暂停保存在本机私有目录。用户主动选择的课表图片在本机OCR，候选必须人工确认。导出备份仅在用户选择文件位置后进行；备份可能含用户自己填写的个人内容，应自行保管。

这属于权限与源码检查的结果，不是对所有系统、依赖或未知缺陷的绝对安全保证。具体检查见 tools/audit/privacy_audit.py 和 dist/隐私检查说明.md。

## 构建与检查

JDK17、Android SDK34与Build Tools35；亦支持Android Studio / Gradle8.9 / AGP8.7.3。离线OCR依赖与模型随源码提供，许可证位于assets/licenses。

```sh
python3 tools/build_apk.py --jdk /path/to/jdk/Contents/Home --sdk /path/to/sdk
python3 tools/audit/privacy_audit.py dist/WeeklyMoments-0.7.1.apk
```

脚本全量重建类文件，执行规则及编解码检查，验证第三方文件摘要，打包ARM64库，用本机私有签名生成APK并验证签名与ZIP对齐。`.signing/`为本地更新身份，不进入分发包。`tests/lib/json-20240303.jar`仅供JVM测试，不进APK。

同次开机额度使用连续时间；运行中重启保守结束正在计时的额度，已手动暂停的余额保留至本周期结束。跨重启的7天冷却依赖系统日期，建议保持自动时间。不能防止清除数据、卸载、停用服务、调时并重启等绕过。分屏、微信分身、变更包名与跨设备额度同步未适配；微信升级后需重新验证。

## 0.7.1 到时提醒点击与流畅度

- 提醒页的跳转先撤除触摸遮挡，再启动目标页面；3 秒内合并连点，避免页面尚未打开就重复盖回。跳转异常或超时会提示，并先解除遮挡 15 秒，允许从桌面／通知进入。
- “紧急使用”立即开始 15 分钟暂停并撤除提醒；记录保存放到后台，即使保存失败也不会撤销当前进程内的暂停。时间按点击时刻记录，不因后台保存延迟而延长。
- 到时提醒页的电话、时钟、去记录、紧急暂停固定在底部；长文在上方独立滚动。
- 提醒规则、闹钟刷新和人物图片解码移出界面线程；刷新请求合并，减少重复通知。后台规则只发布仍对应当前数据的结果。
- 人物保留眨眼和轻点回应，静止时等待下一表情边界；取消持续整图网格绘制，并启用提醒窗口硬件加速。

构建、既有规则／持久化／账号客户端检查以及新增 151 项响应检查通过。151 项检查包含 100 次连点、1 万次刷新合并、启动失败、无前台变化超时、写盘失败与服务销毁回调。60 秒静止状态刷新逻辑模拟为站姿 21 次、原版人物 249 次，**不是实机 FPS 或触控延迟测量**。当前无连接设备，未完成华为实机验证。详细升级与试用见 dist/0.7.1提醒响应修复说明.md。
