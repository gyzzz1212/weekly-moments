## 动画与预览

原生视图通过低幅局部网格形变表现发梢/手指轻动；表情帧只叠加眼睛、嘴部，边缘柔化，遵从系统动画开关。全身不持续左右摆动。具体华为显示效果尚未实测。

preview/index.html为界面设计预览，使用示例数据，不是手机实机截图；原生安装包以应用代码为准。其余v1-v4文件保留为设计历史，不作为当前安装素材。


## 0.5 场景融合与字幕试用

本轮没有重绘人物。使用原生 Canvas 和浏览器渐变遮罩，将原版人物上下、左右边缘融入页面背景，不再以独立矩形图片展示。原有形象与表情素材摘要保持不变。

统一内置 Noto Sans SC 字体，来自 Google Fonts 官方仓库，使用 SIL Open Font License 1.1。字体位于 app/src/main/res/font/focus_sans.ttf，许可位于 app/src/main/assets/licenses/NotoSansSC-OFL.txt。来源：https://github.com/google/fonts/tree/main/ofl/notosanssc 。

预览加入计划、知识、作息、专注入口，以及逐字字幕、点击全文、选时与音效试听。overview-0.5.jpg 为浏览器设计预览截图，不是手机截图。


## 0.5.2 恢复Q版使用场景

计划、知识卡与待办提醒的小对话框恢复原有Q版人物及局部眨眼表情。Q版采用透明素材贴合对话框右侧；首页与朋友圈专注提醒保留原版背景融合展示。没有重绘、删除或替换既有素材。
